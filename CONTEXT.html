ライブラリ更新ウォッチ

読者が選んだライブラリ・フレームワークの公式更新を、1画面で読むための文脈。

Terms

ウォッチリスト: 読者ひとりが追うウォッチ対象の集合。サイトに出る更新はこの集合に限る。正本は設定ファイル。

Avoid: 公開ディレクトリ, カタログ, 全エコシステムの横断索引, 共有ウォッチリスト

設定ファイル: 読者がウォッチ対象と更新源を書くファイル。ウォッチリストの正本。

Avoid: 画面からの登録を必須にする, DB 上のウォッチリスト

ウォッチ対象: ウォッチリストの登録単位。ライブラリまたはフレームワーク。更新源（公式ブログとリリースノート）をこの対象に紐づける。

Avoid: フィード単体の登録, カタログから選ぶだけの項目

読者: ウォッチリストを一人で持つ人。設定ファイルにウォッチ対象と更新源を書き、生成されたタイムラインを読む。

Avoid: 共有ウォッチリスト, 不特定の公開閲覧者, 少人数の共同編集

更新: タイムラインに並ぶ読む単位。公式ブログの記事とリリースノートのどちらも同じ並びに混ざる。サイト上ではタイトルと公式へのリンクを出し、要約があれば添える。本文は公式側で読む。

Avoid: コミットログ, ソーシャル投稿, 本文の転載, サイト内での全文閲覧

要約: 更新源が付けた短い説明。無ければ出さない。本文から作らない。

Avoid: 生成した要約, 本文からの抜粋

タイムライン: 全ウォッチ対象の更新を、1本の時系列に混ぜた並び。読者が見る1画面。新しい順。既読は持たない。

Avoid: ウォッチ対象ごとのリストだけ, 対象別ページ必須, 既読未読

公式ブログ: ライブラリ・フレームワークの公式が出す記事。更新の一種。更新源はフィード。

フィード: RSS または Atom。公式ブログ用の更新源として読者が指定する。

リリースノート: バージョンごとの公式リリース説明。更新の一種。更新源は GitHub Releases の URL。

更新源: ウォッチ対象に紐づく、更新の取り出し元。公式ブログはフィード、リリースノートは GitHub Releases の URL。読者が指定する。

Avoid: ウォッチ対象そのもの, フィード単体のウォッチリスト項目, 自動推定, プリセット必須, ブログページ URL からの推定, 任意 URL
