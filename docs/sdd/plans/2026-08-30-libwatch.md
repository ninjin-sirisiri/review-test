# ライブラリ更新ウォッチ Implementation Plan

**Goal:** `watchlist.yml` からフィードを取り込み、静的なタイムライン HTML を `python3 -m libwatch` で出す。

**Architecture:** 実行時サーバも DB も無い。設定を読み、GitHub Releases URL を Atom フィードに揃え、源を順に GET し、件を正規化・ソート・重複排除して `site/` に書く。失敗した源はスキップし、設定エラーだけ非ゼロで終わる。

**Tech Stack:** Python 3.11+、pytest、PyYAML。HTTP は stdlib `urllib`。RSS 2.0 と Atom 1.0 は stdlib `xml.etree.ElementTree`。HTML エスケープは `html.escape`。

**Spec:** docs/sdd/specs/2026-08-30-libwatch-design.md

## Global Constraints

- 実装は Python 3.11 以上。既定テストはネットワークに出ない。
- HTTP タイムアウト: 更新源あたり 15 秒。
- フィード取得サイズ上限: 2 MiB。
- リダイレクト: 最大 5 回。
- 取り込み: 順次。並列度 1。
- GitHub Actions 間隔: 6 時間。
- User-Agent: `LibWatch/0.1`。
- 要約: 切らない。RSS `description` または Atom `summary` だけ。Atom `content` は使わない。
- フィード件数: フィードが返した件。こちらで上限なし。次ページは辿らない。
- ビルドコマンドはリポジトリ直下で `python3 -m libwatch`。設定の正本は `watchlist.yml`。成果物は `site/index.html`。
- 設定エラーは終了コード非ゼロで `site/` を触らない。取り込み失敗はその源だけスキップしビルド成功してよい。
- 認証ヘッダは付けない。本文転載・生成要約・既読・画面からの登録 UI・GitHub Pages 公開は作らない。
- スキップ行の形式は `skip source: {name} {blog|releases} {url}: {reason}`。
- 空のタイムラインの文言は「更新はまだない」。
- GitHub Releases フィードは常に `https://github.com/{owner}/{repo}/releases.atom`。

`src/libwatch/github_url.py` と `src/libwatch/config.py` を、上のインタフェースどおりに実装する。

`resolve_releases_feed_url`: `urlparse` で scheme は `http`/`https`（大小無視）。`hostname` を小文字化して `github.com` と一致。`username` / `password` があればエラー。クエリとフラグメントは無視。path は `/{owner}/{repo}`、任意で `/releases` または `/releases.atom`、任意の末尾 `/`。owner/repo は `[A-Za-z0-9._-]+`。戻り値は `https://github.com/{owner}/{repo}/releases.atom`（owner/repo の大小はそのまま、ホストは `github.com`）。

`load_watchlist`: UTF-8 で読む。`yaml.safe_load`。トップレベルは dict でキーは `targets` のみ。`targets` は list で 0 件不可。各要素は dict、キーは `name` / `blog` / `releases` のみ。`name` は前後空白除去後に非空。除去後の `name` 重複はエラー。`blog` / `releases` は欠ける・`None`・空白のみなら無し。どちらも無しならエラー。`blog` は `urlparse` で scheme が `http` または `https` の絶対 URL（`hostname` 必須）。フラグメントは除いて保存。`releases` は `resolve_releases_feed_url` に渡す。YAML として読めない・UTF-8 でない・ファイルが無いのは `ConfigError`。

`src/libwatch/feed.py`:
- 不正 XML は `FeedError`。
- RSS: `channel/item`。`title` テキスト、`link` テキスト、`description` のみ要約（`content:encoded` は見ない）。`pubDate` は `email.utils.parsedate_to_datetime`。
- Atom: namespace `http://www.w3.org/2005/Atom`。`entry`。`title`、`link` は `rel="alternate"` を優先し無ければ最初の `href`。`summary` のみ。`content` は無視。日時は `published`、無ければ `updated`。`Z` は UTC。
- 日時が naive なら UTC とみなす。aware なら UTC に変換。
- タイトルが空または空白のみ、リンクが解決後 `http://`/`https://` 以外（`javascript:` 含む）、日時が無い／パース不能は件を落とす（源全体のエラーにしない）。
- リンクは `urllib.parse.urljoin(feed_url, raw_link)`。
- 要約が空または空白のみなら `None`。切らない。HTML タグはここでは剥がさない。

```python
from __future__ import annotations

from libwatch.feed import Entry


def _winner(left: Entry, right: Entry) -> Entry:
    if left.published != right.published:
        return left if left.published > right.published else right
    left_rel = left.kind == "releases"
    right_rel = right.kind == "releases"
    if left_rel != right_rel:
        return left if left_rel else right
    if left.target_name != right.target_name:
        return left if left.target_name < right.target_name else right
    if left.title != right.title:
        return left if left.title < right.title else right
    return left


def merge_entries(entries: list[Entry]) -> list[Entry]:
    by_link: dict[str, Entry] = {}
    for entry in entries:
        current = by_link.get(entry.link)
        if current is None:
            by_link[entry.link] = entry
        else:
            by_link[entry.link] = _winner(current, entry)
    return sorted(
        by_link.values(),
        key=lambda e: (-e.published.timestamp(), e.target_name, e.title),
    )
```
